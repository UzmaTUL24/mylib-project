# MyLib - JavaScript Arithmetic Library

## Description

MyLib is a simple JavaScript library that provides four basic arithmetic operations: addition, subtraction, multiplication, and division.

The project also contains a Mocha and Chai test suite for testing the library functions.

## Functions

- `add(a, b)` - Adds two numbers.
- `subtract(a, b)` - Subtracts the second number from the first.
- `multiply(a, b)` - Multiplies two numbers.
- `divide(a, b)` - Divides the first number by the second. Division by zero throws an error.

## Running the Main Program
